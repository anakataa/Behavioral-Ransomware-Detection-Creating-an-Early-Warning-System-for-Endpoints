Three signals. Two must agree.

Antivirus checks files against a list of known threats. Brand-new ransomware isn't on any list yet. Sentinel ignores names and watches behavior — and acts only when at least two independent signals agree.

File velocity

People save a document every few minutes. Ransomware rewrites dozens per second. Sentinel counts changes in a sliding window and flags speeds no person produces.

alert above 50 files / second

Shannon entropy

Encrypted data looks like pure noise. Sentinel samples the first 4 KB of each changed file and measures how random it is — documents score low, ciphertext scores near the maximum.

alert above 7.5 of 8 bits / byte

Bait files

Sentinel plants hidden decoy files that no real program ever opens. Ransomware walks folders blindly — when it rewrites a bait file, it gives itself away.

12 decoys per protected folder

What happens during an attack

Timings from runs against Sentinel's built-in ransomware simulator on Windows 10.

  2. ≈ 80 msSignals agreeBait and entropy both point at the same burst of activity.
  3. ≈ 0.4 sProcess stoppedSentinel identifies the writing process and terminates it.
  4. afterLogged on your machineEvery event goes to a local audit log. Nothing leaves the computer.

Fully offline

No cloud account, no telemetry. Decisions are made on your computer, so there is no upload delay and no data to leak.

Light on old hardware

Event-driven, no disk scanning. Designed for office PCs and small servers that can't run heavy enterprise security suites.

Works next to your antivirus

Sentinel doesn't replace Windows Defender. It adds a last line of defense for the moment encryption actually starts.

Open source

Every threshold is readable and adjustable. You can see exactly why a process was stopped.

Install on Windows

  1. 1
    Download and unzip

    sentinel-windows-x64.zip contains one portable sentinel.exe. Windows SmartScreen may warn about an unsigned app — choose “More info → Run anyway”.

  2. 2
    Try it safely first

    Open a terminal in the folder and run the demo. It creates its own sandbox with fake documents and a harmless simulator, and opens the live dashboard.

  3. 3
    Protect your folders, watch-only for a day

    Sentinel alerts but never stops anything until you drop --monitor-only. Recommended on a new machine.

Commands

> sentinel.exe demo > sentinel.exe run --watch "%USERPROFILE%\Documents" --monitor-only > sentinel.exe run --watch "%USERPROFILE%\Documents" > sentinel.exe audit -n 20

Linux and developers

$ git clone https://github.com/anakataa/Behavioral-Ransomware-Detection-Creating-an-Early-Warning-System-for-Endpoints.git sentinel $ cd sentinel && pip install . $ sentinel demo $ sentinel run --watch ~/Documents --monitor-only

Python 3.10 or newer. The demo command only ever touches its own sandbox folder.

Questions

What if it stops a program I need?

Archivers and backup tools are on a trusted list, and you can add others. Watch-only mode lets you check a machine before anything is stopped.

Does it replace my antivirus?

No. Keep your antivirus. Sentinel covers the gap where unknown ransomware has already started.

Can it bring back encrypted files?

No. It limits how many files are lost. Keep regular backups.

Is this production software?

No — it is a research prototype built for a diploma thesis. Use it alongside, never instead of, proper backups and security software.
